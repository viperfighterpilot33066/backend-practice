# I.N IT RUNNING

Welcome to our non-profit running community website! Visit us at [https://fir-practice-13a0a.web.app](https://fir-practice-13a0a.web.app)

## About Us
I.N IT RUNNING is a non-profit organization dedicated to building and supporting a vibrant running community.

## Features
- Member Portal with secure authentication
- Interactive Event Calendar
- Community Photo Gallery
- Real-time Updates and Notifications
- Admin Dashboard for Event Management

## Tech Stack
- HTML/CSS/JavaScript
- Firebase Authentication
- Firebase Realtime Database
- Firebase Storage
- Firebase Hosting

## Local Development
1. Clone the repository
2. Set up Firebase configuration
3. Run `firebase serve` for local testing
